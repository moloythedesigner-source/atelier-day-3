# Atelier website

Single-page site: hero, about, recent works, quote, services, clients, contact and footer.

- Open `index.html` in a browser (internet connection needed for Tailwind CDN and Google Fonts).
- Images, logos, SVG patterns and General Sans are embedded in the file.
- Language switcher: English, Deutsch, Français, Italiano (translations live in the script at the bottom).
- To publish with GitHub Pages: push this folder, then Settings > Pages > Deploy from branch `main` / root.
